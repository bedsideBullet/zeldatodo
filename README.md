# Zelda Todo

Zelda Todo is a portfolio project inspired by the Legend of Zelda universe. It is a task management application showcasing modern web development practices using React, Bootstrap, and Vite for a responsive and dynamic user experience.

## Features

- **Task Management**: Add, edit, and delete tasks with a sleek and responsive UI.
- **Thematic Design**: Includes a unique design inspired by the Legend of Zelda.
- **Modern Technologies**: Built with React for dynamic components, Bootstrap for styling, and Vite for lightning-fast development.

## Technologies Used

- **React**: For building interactive and reusable UI components.
- **Bootstrap**: For sleek, responsive design with pre-built components.
- **Vite**: For a fast and optimized development environment.
- **JavaScript, CSS, HTML**: Core technologies for web development.

## Getting Started

### Prerequisites

Make sure you have the following installed on your system:
- Node.js (>= 14.x)
- npm (>= 6.x)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/bedsideBullet/zeldatodo.git
   ```
2. Navigate to the project directory:
   ```bash
   cd zeldatodo
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running the Application

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`.

### Building for Production

To create a production build, run:
```bash
npm run build
```
